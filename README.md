# Korean Radio Alarm

A Volumio music_service plugin for Bookworm that adds Korean radio browsing and a weekly alarm.

## Notes

- This plugin is scaffolded for Bookworm submission workflow and is intentionally minimal.
- This plugin includes direct streaming URLs in `radio_stations.json`; radio stream endpoints can change without notice.
- Broadcaster URLs should be tested on an actual Volumio device before submission.
- Settings now support three fixed alarm slots (`alarm_1` to `alarm_3`) with independent time, station, volume, and weekday settings.
